About Me

I'm a Bachelor of Computer Applications graduate (2025) from Rani Channamma University, Belagavi, with a genuine interest in software development, web development and data-related technologies. My focus during my degree has been on understanding how applications are built end-to-end — from the logic on the server to the interface a user actually interacts with.

I enjoy working across the stack: writing structured code in Java, Python and C, building web interfaces with HTML, CSS and JavaScript, and connecting them to databases using PHP and MySQL. I've applied this through academic and hackathon projects, including a car rental management system and a MERN-based recruitment concept, which gave me hands-on exposure to planning, building and refining a working application.

I'm early in my career and still learning — but I approach every project with curiosity, patience and a willingness to dig into problems until they're solved. My goal is to build a strong, long-term career in the IT industry, and to keep growing into emerging technologies as I gain more real-world experience.
